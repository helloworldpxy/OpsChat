# 产品说明书

## 1. 产品概述

### 1.1 产品名称

智能运维Agent（OpsChat）

### 1.2 产品版本

V1.0.0

### 1.3 产品简介

本产品是一款部署于通用 Linux 操作系统的智能运维 Agent 系统，通过 B/S 架构提供自然语言交互界面，让运维人员能够通过自然语言与操作系统交互，实现智能运维。

### 1.4 目标用户

- 系统运维工程师
- IT管理人员
- 技术支持人员

## 2. 功能特性

### 2.1 智能对话

- 支持自然语言输入
- 流式输出实时显示
- Markdown格式渲染
- 对话历史管理

### 2.2 系统监控

- CPU使用率监控
- 内存使用率监控
- 磁盘使用率监控
- 网络状态监控

### 2.3 运维工具（24个MCP工具）

- 系统感知：CPU/内存/磁盘/系统信息
- 原生命令：lsof端口占用、dmesg内核日志、iostat磁盘IO、netstat网络连接
- 进程管理：进程列表、进程详情、僵尸进程检测、终止进程
- 服务管理：服务列表、服务状态、启动/停止/重启服务
- 文件操作：删除文件、修改权限、配置文件漂移检测
- 网络诊断：Ping测试、网络连接状态
- 智能诊断：一键系统健康诊断（集成根因分析）

### 2.4 安全防护（三层防护）

**第一层：输入过滤**
- Prompt注入防御（38种模式）
- 危险命令检测
- 敏感信息泄露检测

**第二层：输出校验（11条规则）**
- 系统关键路径保护
- 关键进程/服务保护
- 不安全权限拦截
- 配置基线文件保护
- 安全监控服务保护
- LLM输出内容校验

**第三层：执行沙箱**
- 路径限制、命令白名单、资源限制

- 操作确认机制

### 2.5 智能根因分析

- 六维度异常检测（CPU/内存/磁盘/进程/日志/网络）
- 关联分析（CPU高→高CPU进程→是否异常）
- 根因推断（OOM→内存泄漏→具体进程）
- 系统健康评分（0-100分）
- 修复建议

### 2.6 自定义工具

- 用户可通过UI创建自定义MCP工具
- 支持Shell命令和Python脚本两种类型
- 提供预置工具模板（端口检查、服务状态、文件信息等）
- 参数使用JSON Schema定义，支持自动校验
- 自定义工具与内置工具统一注册、统一安全校验

### 2.7 深色主题

- 支持明暗主题切换
- 切换状态自动持久化保存
- 所有页面统一适配深色主题

### 2.8 审计追溯

- 思维链记录
- 操作日志
- 安全事件记录

## 3. 安装说明

### 3.1 环境要求

- 操作系统：通用 Linux 发行版（含 LoongArch 等国产架构） / Windows（部分功能）
- Python 3.10+
- Conda：Miniconda或Anaconda
- Docker（可选）

### 3.2 安装步骤

#### 方式一：Conda安装

```bash
# 1. 克隆项目
git clone <repository-url>
cd opschat

# 2. 创建Conda环境
conda env create -f environment.yml

# 3. 激活环境
conda activate opschat

# 4. 配置环境变量
cp .env.example .env
# 编辑.env文件，配置API Key

# 5. 启动服务
python run.py
```

#### 方式二：Docker安装

```bash
# 1. 构建镜像
docker build -t opschat .

# 2. 运行容器
docker run -d -p 8000:8000 --env-file .env opschat
```

### 3.3 配置说明

编辑`.env`文件：

```env
# LLM配置
LLM_API_KEY=your_api_key_here
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-v4-flash

# 服务器配置
HOST=0.0.0.0
PORT=8000
```

## 4. 使用说明

### 4.1 访问系统

启动服务后，在浏览器中访问：http://localhost:8000

### 4.2 配置API

1. 点击左侧导航栏"设置"
2. 选择模型提供商（DeepSeek、MiMo、Qwen等）
3. 输入API Key
4. 选择模型
5. 点击"保存配置"
6. 点击"测试连接"验证配置

### 4.3 使用对话功能

1. 点击左侧导航栏"对话"
2. 在输入框输入问题，例如：
   - "帮我查看系统状态"
   - "检查磁盘空间"
   - "列出运行中的进程"
3. 按Enter发送
4. 等待Agent响应

### 4.4 查看监控

1. 点击左侧导航栏"监控"
2. 查看CPU、内存、磁盘使用率
3. 查看MCP工具状态

### 4.5 查看审计日志

1. 点击左侧导航栏"审计日志"
2. 查看思维链推理过程
3. 可按阶段筛选日志

## 5. API文档

### 5.1 对话接口

```
POST /api/chat/
Content-Type: application/json

{
    "message": "帮我查看系统状态",
    "session_id": "session_123",
    "stream": false
}
```

### 5.2 工具接口

```
GET /api/tools/          # 获取所有工具
GET /api/tools/llm       # 获取LLM可用工具
GET /api/tools/{name}    # 获取工具详情
```

### 5.3 审计接口

```
GET /api/audit/logs      # 获取审计日志
GET /api/audit/traces    # 获取追踪列表
GET /api/audit/trace/{id} # 获取追踪详情
DELETE /api/audit/traces  # 清除追踪
```

### 5.4 设置接口

```
GET  /api/settings/              # 获取设置
POST /api/settings/api           # 保存API配置
POST /api/settings/system        # 保存系统配置
POST /api/settings/test-connection # 测试连接
```

### 5.5 模型接口

```
GET /api/models/          # 获取所有模型
GET /api/models/{provider} # 获取提供商模型
```

## 6. 常见问题

### 6.1 API连接失败

**问题**：测试连接时提示失败

**解决方案**：
1. 检查API Key是否正确
2. 检查网络连接
3. 检查API Base URL是否正确
4. 确认API服务是否可用

### 6.2 工具执行失败

**问题**：执行工具时返回错误

**解决方案**：
1. 检查是否有足够的权限
2. 检查参数是否正确
3. 查看审计日志了解详情

### 6.3 安全拦截

**问题**：正常操作被安全护栏拦截

**解决方案**：
1. 查看安全检查详情
2. 调整安全设置（不推荐）
3. 联系管理员
