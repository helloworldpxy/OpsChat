### 3.2 测试结论

1. 安全模块功能正常，能够有效防御Prompt注入攻击（38种注入模式）
2. 输出校验正确拦截高危操作（11条安全规则全部生效）
3. LLM输出内容校验正常，能拦截危险shell命令
4. API接口响应正常
5. MCP工具注册和执行正常（24个工具）
6. 智能根因分析模块工作正常
7. 配置漂移检测功能正常
8. 权限审批链路正常：once/always/reject、流式 confirm、会话绑定、sudo 提权
9. 自定义工具安全限制生效：python 类型禁用、危险命令模板拦截、high 风险强制审批、工具名校验
10. DeepSeek V3 tokenizer 精确计数与 provider usage 优先逻辑正确
11. FTS 触发器（INSERT/DELETE/UPDATE）与源表数据同步，删除会话不产生孤儿索引
12. 审计导出 CSV/JSON 正常，空库导出、非法格式与非法时间参数均返回预期状态码
13. 模型 API 密钥加密落库，读接口不泄漏明文，掩码占位不覆盖真实密钥

## 4. 测试命令

```bash
# 运行所有测试
pytest tests/

# 运行安全模块测试

# 运行工具测试
pytest tests/test_tools.py -v

# 运行API测试
pytest tests/test_api.py -v

# 生成覆盖率报告
pytest --cov=backend tests/
```
