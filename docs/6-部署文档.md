# 部署文档

## 1. 部署概述

### 1.1 部署方式

本项目支持以下部署方式：
- 本地开发环境部署
- Docker容器化部署
- 通用 Linux（含 LoongArch 等国产架构）部署

### 1.2 环境要求

| 组件 | 要求 |
|------|------|
| 操作系统 | Linux (含 LoongArch 等国产架构) / Windows / macOS |
| Python | 3.10+ |
| Conda | Miniconda 或 Anaconda |
| Docker | 20.10+ (可选) |
| 内存 | >= 2GB |
| 磁盘 | >= 1GB |

## 2. 本地开发环境部署

### 2.1 安装Conda

```bash
# 下载Miniconda
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh

# 安装
bash Miniconda3-latest-Linux-x86_64.sh

# 配置龙芯Python仓库（仅LoongArch平台需要）
wget https://cloud.loongnix.cn/releases/loongarch64/python/set-pip.sh
chmod +x set-pip.sh
./set-pip.sh
```

### 2.2 创建环境

```bash
# 克隆项目
git clone <repository-url>
cd opschat

# 创建Conda环境
conda env create -f environment.yml

# 激活环境
conda activate opschat
```

### 2.3 配置环境变量

```bash
# 复制示例配置
cp .env.example .env

# 编辑配置
vim .env
```

配置内容：
```env
# LLM配置
LLM_API_KEY=your_api_key_here
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-v4-flash

# 数据库配置
DATABASE_URL=sqlite:///./data/audit.db

# 服务器配置
HOST=0.0.0.0
PORT=8000

# 日志配置
LOG_LEVEL=INFO
```

### 2.4 启动服务

```bash
python run.py
```

访问 http://localhost:8000

## 3. Docker部署

### 3.1 构建镜像

```bash
docker build -t opschat .
```

### 3.2 运行容器

```bash
docker run -d \
  --name opschat \
  -p 8000:8000 \
  --env-file .env \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/logs:/app/logs \
  opschat
```

### 3.3 使用Docker Compose

```bash
# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

### 3.4 龙芯Docker配置

```json
{
  "registry-mirrors": ["https://cr.loongnix.cn"]
}
```

## 4. 通用 Linux 部署

### 4.1 系统准备

```bash
# 更新系统
sudo yum update -y

# 安装Docker
sudo yum install -y docker

# 启动Docker
sudo systemctl start docker
sudo systemctl enable docker
```

### 4.2 配置Docker镜像仓库

```bash
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://cr.loongnix.cn"]
}
EOF

sudo systemctl restart docker
```

### 4.3 部署应用

```bash
# 克隆项目
git clone <repository-url>
cd opschat

# 配置环境变量
cp .env.example .env
vim .env

# 使用Docker Compose部署
docker-compose up -d
```

### 4.4 访问应用

在浏览器中访问：http://localhost:8000

## 5. 反向代理配置

### 5.1 Nginx配置

```nginx
server {
    listen 80;
    server_name opschat.example.com;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        
        # SSE支持
        proxy_set_header Connection '';
        proxy_http_version 1.1;
        chunked_transfer_encoding off;
        proxy_buffering off;
        proxy_cache off;
    }
}
```

### 5.2 启用HTTPS

```bash
# 安装certbot
sudo yum install -y certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d opschat.example.com
```

## 6. 系统服务配置

### 6.1 创建systemd服务

```bash
sudo tee /etc/systemd/system/opschat.service <<EOF
[Unit]
Description=OpsChat Service
After=network.target

[Service]
Type=simple
User=opschat
WorkingDirectory=/opt/opschat
Environment=PATH=/opt/opschat/venv/bin
ExecStart=/opt/opschat/venv/bin/python run.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
```

### 6.2 启用服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable opschat
sudo systemctl start opschat
```

## 7. 故障排查

### 7.1 查看日志

```bash
# 应用日志
tail -f logs/opschat.log

# Docker日志
docker logs -f opschat

# systemd日志
journalctl -u opschat -f
```

### 7.2 常见问题

**问题**：端口被占用
```bash
# 查找占用端口的进程
lsof -i :8000

# 杀死进程
kill -9 <PID>
```

**问题**：权限不足
```bash
# 修改文件权限
chmod -R 755 /opt/opschat
chown -R opschat:opschat /opt/opschat
```

**问题**：数据库锁定
```bash
# 删除锁定文件
rm -f data/audit.db-journal
```
